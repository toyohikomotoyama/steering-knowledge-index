# Steering + Knowledge Index：AI支援プロジェクトの三層記憶モデル

[English](README.md)

長期のAI支援ソフトウェア開発で生まれた、プロジェクト記憶の三層モデルについてのユースケース提案です。

- `docs/` — 現在の正しい仕様・成果物
- `.steering/` — 作業中の現在地と時系列の経験記録
- `.knowledge-index/` — 関連するSteeringへ戻るための索引

> **Steeringは「舵取り」である。今日の航海を記録し、その記憶を明日の航海の舵取りに使う。**

このモデルには、さらに二つの実務上の効果があります。

1. 過去の具体的な経験から、類似したリスクを早めに察知できる。
2. コードと同じリポジトリに記録を置くことで、リポジトリ自体が逆引き可能な引継ぎ資料になる。
