# システム仕様

## 1. 文字コード

### 1.1 ソースファイル
- 新規・現行領域はUTF-8を標準とする。
- レガシー領域にはShift_JISで保存されたファイルが残存している。
- レガシーファイルの保存形式変更時は、呼び出し元と変換処理への影響を確認する。

### 1.2 HTTPレスポンス
- ブラウザ向けHTMLレスポンスはUTF-8で返却する。
- アプリケーション配下では上位の既定値とは別にUTF-8を指定する。
- 実環境は前段プロキシを経由する。クライアントから観測されるServer情報だけでアプリケーションサーバを特定しない。

## 2. ファイルダウンロード

### 2.1 ダウンロード前確認
- 対象ファイルのダウンロード前に確認ダイアログを表示する。
- 「続行」でダウンロードを開始する。
- 「キャンセル」ではダウンロードしない。
- ダイアログ表示時点ではダウンロードリクエストを送信しない。

## 3. アカウントデータ出力

### 3.1 出力前確認
- アカウントデータ出力は確認画面を経由する。

### 3.2 出力対象
- 表示中の検索条件を出力条件として引き継ぐ。
- 出力対象の確定はサーバ側で行う。
- 画面表示件数と実際の出力件数が一致しない場合がある。

## 4. リリース前確認
- コード修正完了と実機確認完了は別状態として扱う。
- 外部仕様確認が必要な項目は仕様確定後に実装する。
